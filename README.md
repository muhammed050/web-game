# NEON CITY

A browser-based 3D open-world multiplayer game built with React, TypeScript, Vite, Three.js, Zustand and Supabase.

## Development

1. Copy `.env.example` to `.env.local`.
2. Add your Supabase URL and publishable/anon key.
3. Apply `supabase/schema.sql` to your Supabase project.
4. Run `npm install` and `npm run dev`.

The MVP includes a 3D city, third-person movement, vehicles, jobs, realtime player presence, chat, profile persistence, economy RPCs, responsive controls and a mobile HUD.
